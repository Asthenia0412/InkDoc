# 开发笔记

## 2026-04-10 项目启动

### 技术选型

选择了 **Tauri v2** 而非 Electron，主要考虑：

1. **包体积**：Tauri 打包后约 5-10MB，Electron 通常 100MB+
2. **内存占用**：Rust 后端内存管理更高效
3. **性能**：文件 I/O 和 Markdown 解析由 Rust 处理

### 架构决策

- **Block 协议**：前后端通过统一的 `Block` 结构通信
- **ID 策略**：`{行号}:{内容哈希}` 的混合 ID，保证 React key 稳定性
- **Undo**：MVP 阶段使用前端 Zustand 状态回溯
