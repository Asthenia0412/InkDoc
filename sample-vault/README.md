# 欢迎使用 Lark Local

这是一款**本地优先**的 Markdown 编辑器，灵感来自飞书的视觉设计和 Obsidian 的文件管理理念。

## 核心特性

- **飞书风格渲染**：标题、列表、引用块都经过精心设计
- **本地文件管理**：直接操作磁盘上的 `.md` 文件
- **实时监听**：外部修改自动同步到编辑器
- **高性能**：Rust 后端处理 I/O 和解析

## 使用方法

1. 点击左侧的文件夹图标打开一个目录
2. 在文件树中点击 `.md` 文件查看渲染效果
3. 编辑内容会自动保存到磁盘
